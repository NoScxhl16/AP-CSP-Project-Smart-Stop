# AP-CSP-Project-Smart-Stop
Smart Stop is a bus pickup simulator created for AP Computer Science Principles. The project models student transportation by allowing users to change factors such as student population, bus availability, weather conditions, and wait-time goals. As these conditions change, the simulation updates transportation efficiency and risk levels in real time.

The idea for this project came from the challenges schools face when managing student pickup and transportation. Long wait times, overcrowding, limited bus availability, and poor weather conditions can all affect how efficiently students are transported. Smart Stop was designed to demonstrate how programming can be used to model these situations and analyze their impact.

One of the main goals of the project was to create a system that responds dynamically to user actions. Instead of producing fixed results, the simulation continuously updates as students are added, buses arrive, and conditions change. The project uses functions, loops, conditionals, lists, and event-driven programming to create an interactive experience.

To run the project, open CMU CS Academy and create a new Python project. Copy the Smart Stop source code into the editor and run the program. Once the simulation starts, users can add students, add buses, change weather conditions, adjust the wait-time goal, and observe how those decisions affect transportation efficiency and risk.

Questions about the project can be answered by reviewing the code comments, project documentation, and Google Site portfolio. The code is organized into separate functions to make it easier to understand how each part of the simulation works.
